# エピック D: 履歴を見る（第 1 段階分）

## US-10 トップから履歴に行く
美香として、週末にまとめて振り返るために、トップから履歴へすぐ移動したい。
- 対応: FR-T03, H07
- AC:
  - [x] トップに「履歴を見る」がある
  - [x] 履歴一覧の戻るリンクがトップ（`/`）に向いている

## US-11 一覧に条件が出る
美香として、どの志望先向けに練習したか分かるように、一覧に条件を表示してほしい。
- 対応: FR-H01, H03, H04, H05, D01
- AC:
  - [x] 各行に「テーマ／笑顔 NN%／IT・エンジニア・新卒・優しい／日時」が出る
  - [x] 新しい順、件数表示、0 件の案内、笑顔の棒グラフ
  - [x] 詳細にメモも表示される
