# エピック F: プロフィールを登録して深掘りを具体的にする

## US-20 ES と職務経歴書を登録する
美香として、「職務経歴書にある○○について」と本番同様に聞かれるために、ES と職務経歴書を一度登録しておきたい。職務経歴書は履歴書と同じ書き方（年・月・内容）で書きたい。
- 対応: FR-F01〜F06, F09, X10
- AC:
  - [x] トップの「プロフィール設定」から `/profile` に移動できる
  - [x] 「ES」と「職務経歴書」が別のセクションに分かれている
  - [x] ES は複数行テキストで、2,000 文字を超えて入力できない
  - [x] 職務経歴書は「年・月・内容」の行を「＋ 行を追加」で増やせ、各行を削除できる。30 行を超えて追加できない
  - [x] 免許・資格の欄がある（500 文字）
  - [x] 「保存する」1 つで全部が保存され、開き直すと内容が残っている
  - [x] 「トップへ戻る」がある

## US-20a AI に送られることを知ったうえで書く
陸として、どこまで書いてよいか判断するために、入力した会社名・学校名が AI に送られることを入力欄の近くで知りたい。
- 対応: FR-F05
- AC:
  - [x] ES・職務経歴書・免許資格の各欄の直下に「ここに入力した会社名・学校名などの情報は、面接の質問生成のために AI（外部サービス：Groq）へ送信されます。書きたくない情報は省略してください」が表示される
  - [x] 注意書きは保存前から見えている（保存後に出るのではない）

## US-21 プロフィールが深掘りに使われる
美香として、登録した実績を踏まえた質問をしてもらうために、面接と講評の両方でプロフィールを参照してほしい。
- 対応: FR-F07, F08, T04, X01, X02
- AC:
  - [ ] プロフィール登録後の模擬面接で、ES の内容や職務経歴（会社名・在籍期間）に触れた質問が出る
  - [ ] 講評モードでも登録内容を踏まえた講評になる
  - [ ] 未登録でも模擬面接・講評は動く
  - [ ] 未登録のときトップに「プロフィールを登録すると深掘りが具体的になります」と出る
  - [ ] プロフィールの本文はブラウザから API に送られていない（サーバー側で読む）
