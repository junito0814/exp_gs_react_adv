# 第 3 段階（余裕があれば）

## US-24 面接の段階・企業タイプを選ぶ
美香として、最終面接向けに志望度を問われる練習をするために、段階と企業タイプを選びたい。
- 対応: FR-T01（`stage` `company`）
- AC:
  - [ ] 一次／二次／最終、大手／中小／ベンチャー／公的機関 が選べ、出題傾向が変わる

## US-25 考える時間がある
陸として、本番の「間」に慣れるために、質問の後に数秒の考える時間がほしい。
- 対応: FR-I19
- AC:
  - [ ] 質問表示後 N 秒はカウントダウンが出て録音を開始できない

## US-26 短い回答を促される
陸として、一言で終わってしまう癖を直すために、短すぎる回答を面接官に促してほしい。
- 対応: FR-I20
- AC:
  - [ ] 短い回答に「もう少し詳しく」が返り、往復数は消費しない。2 回目はそのまま進む

## US-27 前回の条件が初期値になる
美香として、毎回選び直さずに済むように、前回の条件を覚えていてほしい。
- 対応: FR-T05
- AC:
  - [ ] 次回トップを開いたとき前回の条件・`background` が入っている

## US-28 履歴から再挑戦する
陸として、前日に同じテーマを繰り返すために、履歴からそのまま練習に入りたい。
- 対応: FR-D05
- AC:
  - [ ] 詳細に「このテーマでもう一度（講評）」「同じ条件で模擬面接」があり、条件・テーマ付きで遷移する

## US-29 前回の回答と比較される
美香として、練り直しの効果を知るために、同じテーマの前回回答との比較を講評に含めてほしい。
- 対応: REQ-31
- AC:
  - [ ] 同じテーマの 2 回目以降で「前回より／前回あった○○が抜けた」の指摘が入る。初回は比較なし

## US-30 NG 表現を指摘される
美香として、現職への不満が口に出る癖を直すために、NG 表現を指摘してほしい。
- 対応: REQ-32
- AC:
  - [ ] ネガティブ表現・他責・数字のない実績が指摘され、言い換え例が付く
