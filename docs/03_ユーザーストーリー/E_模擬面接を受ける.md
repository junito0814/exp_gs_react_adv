# エピック E: 模擬面接を受ける

## US-12 面接官から質問が出る
陸として、本番のように質問を選べない状態で練習するために、面接官から出題されたい。
- 対応: FR-I01, I02, I03, X02、要件 5.3
- AC:
  - [ ] トップの「模擬面接を始める」で条件付きで `/interview` に遷移し、条件が上部に表示される
  - [ ] 「面接を始める」を押すと、カメラが起動し、数秒以内に最初の質問が表示される
  - [ ] 質問は条件に合っている（新卒には学生時代の話、中途には実績・転職理由、`background` があればその差分）
  - [ ] 質問は 1 文で、講評や前置きが混ざっていない
  - [ ] 何度か始め直すと違うテーマが出る

## US-13 質問が読み上げられる
美香として、本番のように耳で質問を聞くために、質問を自動で読み上げてほしい。
- 対応: FR-I04
- AC:
  - [ ] 質問が表示されると同時に音声が流れる
  - [ ] 読み上げに失敗してもテキストは表示され、録音に進める

## US-14 声だけで回答する
陸として、書き直しながら考えられない本番の状況に慣れるために、回答は録音だけにしてほしい。
- 対応: FR-I05, I06, I07, I16, I17
- AC:
  - [ ] 回答欄はテキスト入力できず、録音ボタンのみ
  - [ ] 録音中は経過秒数が表示される。上限はない
  - [ ] 停止すると文字起こし結果が表示され、編集できない
  - [ ] 文字起こしが空のときは「送信」できない
  - [ ] 送信後に前の回答へ戻る手段がない
  - [ ] マイクが使えないときだけテキスト入力欄が出る

## US-15 回答に応じた深掘りが来る
美香として、自分の答えの弱いところを見つけるために、回答の内容を踏まえた深掘り質問がほしい。
- 対応: FR-I08, I09, X02、要件 5.1, 5.3
- AC:
  - [ ] 送信すると、直前の回答の言葉を引用・参照した深掘り質問が返る
  - [ ] テーマが途中で変わらない
  - [ ] 「厳しい」では根拠・数字を求め、「意地悪」では矛盾や「他社でもよいのでは」を突く
  - [ ] どのレベルでも不適切な属性の質問・人格否定がない
  - [ ] 3 往復目の送信後は質問が来ず、総評に進む

## US-16 途中でやめる
美香として、時間がないときに切り上げるために、面接を中断してそこまでの総評がほしい。
- 対応: FR-I11
- AC:
  - [ ] 「面接中断」がどの状態でも押せ、確認ダイアログが出る
  - [ ] 1 往復以上あれば、そこまでの内容で総評が出て保存される
  - [ ] 0 往復なら保存されずトップに戻る

## US-17 総評をもらう
陸として、内容だけでなく表情と話し方も直すために、3 軸の総評がほしい。
- 対応: FR-I10, I12, I14, I15, X03、要件 5.4
- AC:
  - [ ] 「■ 内容面／■ 表情／■ 話し方」の 3 セクションで表示される
  - [ ] 表情には各往復の笑顔スコア（例：35% → 62% → 70%）が反映されている
  - [ ] 話し方には各回答の秒数・長さに基づく指摘がある
  - [ ] 面接官レベルに応じた口調になっている
  - [ ] 既存の読み上げ UI で手動再生できる（自動では流れない）
  - [ ] 「履歴を見る」「トップへ戻る」がある

## US-18 自動で保存される
美香として、保存し忘れをなくすために、面接が終わったら自動で記録されてほしい。
- 対応: FR-I13, X07
- AC:
  - [ ] 総評が出た時点で履歴に 1 件増えている（保存ボタンを押していない）
  - [ ] 保存に失敗したらエラーと「再保存」ボタンが出て、押すと保存される
  - [ ] 保存された記録に条件・往復（質問・回答・笑顔・秒数）・総評が含まれる

## US-19 失敗しても続けられる
陸として、通信が不安定でも面接をやり直さずに済むように、失敗した処理だけ再試行したい。
- 対応: FR-I18, NFR-06
- AC:
  - [ ] 質問取得・総評生成に失敗するとエラーと「もう一度」ボタンが出る
  - [ ] 「もう一度」で同じリクエストが再送され、それまでの往復は消えていない
