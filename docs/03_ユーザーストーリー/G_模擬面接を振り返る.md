# エピック G: 模擬面接を振り返る

## US-22 タブで模擬面接と講評を分けて見る
美香として、模擬面接だけを見返すために、履歴をタブで切り替えたい。
- 対応: FR-H02, X06
- AC:
  - [ ] 一覧に「模擬面接」「講評」のタブがあり、既定は模擬面接
  - [ ] タブごとに件数・棒グラフ・一覧が切り替わる
  - [ ] URL に `?mode=` が付き、リロードしてもタブが保たれる

## US-23 往復をそのまま読み返す
陸として、どこで詰まったかを確認するために、質問と回答の往復を順に読み返したい。
- 対応: FR-D02
- AC:
  - [ ] 詳細に「Q. 質問／A. 回答／笑顔 NN%／MM 秒」が往復順に並ぶ
  - [ ] 最後に総評が表示される
  - [ ] 面接条件が表示される
