# エピック C: 講評モードで 1 問ずつ練習する

## US-06 定番テーマから選ぶ
陸として、新卒でよく聞かれる質問を練習するために、区分に合った定番テーマを選びたい。
- 対応: FR-P02, P03
- AC:
  - [x] 新卒：自己紹介／ガクチカ／自己PR／志望動機／長所・短所／挫折経験 が並ぶ
  - [x] 中途：自己紹介／職務経歴・実績／転職理由／志望動機／長所・短所／マネジメント経験 が並ぶ
  - [x] 新卒のとき「転職理由」は出ない

## US-07 自分でテーマを入力する
美香として、実際の面接で聞かれた質問を復習するために、テーマを自由に入力したい。
- 対応: FR-P02
- AC:
  - [x] プルダウンで「自由入力」を選ぶとテキスト欄が現れる
  - [x] 入力したテーマが講評のプロンプトに使われる（講評文に「お題」として反映される）
  - [x] 自由入力が空のときは「コーチに見てもらう」を押せない
  - [x] 100 文字を超えて入力できない

## US-08 面接官レベルに応じた講評を受ける
陸として、慣れてきたら厳しめの講評で鍛えるために、面接官レベルを講評にも反映してほしい。
- 対応: FR-P04, P08, X01、要件 5.1
- AC:
  - [x] 従来の「口調」セレクト（やさしめ／スパルタ／ていねい／関西弁）が画面にない
  - [x] 「優しい」では肯定から入り、「厳しい」では根拠・数字を求め、「意地悪」では弱点を突く講評になる
  - [x] どのレベルでも人格否定・不適切な属性への言及がない
  - [x] 講評は「良かった点／改善点とアドバイス／深掘り質問」の 3 セクションで 250〜350 文字程度

## US-09 声で回答し、講評を聞き、保存する（既存）
陸として、これまで通り録音で回答し、講評を読み上げ、記録を残したい。
- 対応: FR-P05〜P07, P09〜P11
- AC:
  - [x] 「🎤 録音する」→「■ 録音停止して文字にする」で文字起こし結果が回答欄に入る
  - [x] 笑顔率がリアルタイムに表示される
  - [x] 回答が空・生成中はボタンが押せない
  - [x] 講評を読み上げ、停止／続き／最初から、音量・速度が使える
  - [x] 通信失敗時にエラー文が出て再度押せる
  - [x] 「保存する」で面接条件・テーマ・回答・笑顔スコア・講評・メモが保存される
