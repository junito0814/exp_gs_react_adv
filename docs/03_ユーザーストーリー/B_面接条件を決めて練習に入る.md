# エピック B: 面接条件を決めて練習に入る

## US-03 面接条件を選ぶ
美香として、志望先に合った質問で練習するために、トップ画面で業界・職種・区分・面接官レベルを選びたい。
- 対応: FR-T01, T06、要件 3 章
- AC:
  - [ ] 志望業界（8 択）・志望職種（7 択）・区分（新卒／中途）・面接官レベル（優しい／厳しい／意地悪）がプルダウンで選べる
  - [ ] 初期値が入っていて、何も変えずに「講評モードで練習」を押せる
  - [ ] トップを開いてもカメラのランプが点かない
  - [ ] 年齢・性別などの入力欄がない

## US-04 現職／学部を伝える
美香として、「商社からメーカーへ、なぜ？」のような自分に合った深掘りをしてもらうために、現職を一言添えたい。
陸として、「文系からなぜエンジニア？」を聞いてもらうために、学部・専攻を添えたい。
- 対応: FR-T01（`background`）
- AC:
  - [ ] 区分で「中途」を選ぶと欄のラベルが「現職（業界・職種・年数）」、「新卒」だと「学部・専攻」に変わる
  - [ ] 空のままでも練習を始められる
  - [ ] 欄の下に「入力すると質問が具体的になります」と表示される
  - [ ] 100 文字を超えて入力できない

## US-05 条件を引き継いで講評モードに入る
陸として、選んだ条件で練習するために、講評画面に条件が引き継がれてほしい。
- 対応: FR-T02, P01, P12
- AC:
  - [ ] 「講評モードで練習」で `/practice?industry=...&job=...&career=...&level=...&background=...` に遷移する
  - [ ] 講評画面の上部に「IT／エンジニア／新卒／優しい」のように条件が表示される
  - [ ] リロードしても条件が消えない
  - [ ] 条件なしで `/practice` を直接開くとトップに戻される
  - [ ] 「トップへ戻る」リンクがある
