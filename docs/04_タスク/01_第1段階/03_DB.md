## メモ

- Neon への接続は IPv6 でタイムアウトするため、`NODE_OPTIONS=--no-network-family-autoselection` が必要（`npm run dev` `npm run db:push` に設定済み）。
- 以後のスキーマ変更も `npm run db:generate`（記録用 SQL 生成）→ `npm run db:push`（適用）の順で行う。
