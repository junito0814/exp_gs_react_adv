## 実装の記録

- 方式は **プロンプトのみ**（コード側の語句検出や外部の判定モデルは使わない）。
  NG 表現の判定は文脈依存（「残業が多い」が不満か事実の説明か）なので、語句リストでは誤検出しやすい。
- TypeSafe AI の Jev（型付き判定を返す System One モデル）も検討したが、
  文章を生成しないため言い換え例は作れず、Groq との併用が前提になる。
  API キーが無いため今回は見送り（将来、生成した質問の禁止事項チェックに使う余地はある）。
- NG 指示を足すと出力が伸びて 462〜533 字になり、「意地悪」が勝手に見出しを追加したため、
  「見出しを増やさない」「450 文字を超えない」「→ 言い換え例：「…」の形で書く」を追記して収めた。
