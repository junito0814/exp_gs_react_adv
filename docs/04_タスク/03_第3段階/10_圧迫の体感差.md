# 圧迫レベルの体感差（改善 #45）

対応：REQ-16, REQ-20／決定事項 7.1／要件定義 5.0

#44 で「圧迫」に改名したが、3 往復通すと丁寧な語尾の詰問にとどまり、レベルを変えた実感が乏しかった。
声・詰め方・見た目の 3 つを変えて「人が変わったよう」にする。

## 完了条件

- [x] 3 レベルで声が違う

- [x] 圧迫でも人格否定・決めつけが無い

## 実装で分かったこと

- system の「質問は 100 文字以内の **1 文**」という指示と、「一度否定してから問い直す」（2 文必要）が
  衝突していた。最初の実装では否定も志望度の疑いも出なかった。
  → 圧迫だけ「140 文字以内・2 文まで」に緩めた（`QUESTION_MAX_CHARS_HARSH`）。
- 深掘りの指示（user メッセージ）が全レベル共通の定数だったため、圧迫の振る舞いが効いていなかった。
  → `buildFollowUpPrompt(conditions, answered)` に変え、レベルと往復数で内容を変える。
  志望度を疑う質問は **最後の質問で 1 回だけ** 使うよう、それ以前は明示的に禁止した。

## 実測（T-310.6・圧迫／中途／商社→メーカー企画）

```
Q1（80字）営業企画10年という長いキャリアですが、自己紹介でその経験がメーカーの企画・マーケに
          どう活きるか具体的に述べられますか？具体的な実績を交えて簡潔にお願いします。
Q2（55字）「既存の取引先を担当し企画もやっていた」とは他の営業でも言えるでしょう。
          具体的にどんな企画で、成果は何ですか？
Q3（95字）新商品のアイデアを出したとだけでは他の人でも言えるし、売上貢献の具体的数字が
          示されていません。実際に何％増やしたのか、金額でいくらか、そしてそれが
          当社でなくても同様にできるのではないですか？
```

| 確認項目 | 結果 |
| --- | --- |
| 一度否定してから問い直す | Q2「他の営業でも言えるでしょう」／Q3「他の人でも言えるし」 |
