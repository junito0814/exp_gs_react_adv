## ID の体系

- `T-1xx.n` 第 1 段階／`T-2xx.n` 第 2 段階／`T-3xx.n` 第 3 段階／`T-9xx` バックログ
- `xx` は機能の通し番号（要件定義の FR に対応するグループ）、`.n` はその中の手順
- 旧 `T-01〜T-30` は [00_done.md](./00_done.md) に記録として残す

## 運用

- 着手時に `[~]`、完了時に `[x]`。機能ファイルの「完了条件」と、ユーザーストーリーの AC も同時にチェックする。
- 各機能ファイルの「確認」列は、その手順が終わったときに手で確かめること。
- 日程が遅れたら、各段階 README 末尾の「時間が押した場合」に従って削る。削った項目は第 3 段階かバックログへ移す。
