# 考える時間 — 取り下げ

対応：US-25（取り下げ）／FR-I19（取り下げ）／決定事項 5（取り下げ）

自動録音（FR-I05）を入れた時点で、面接官が話し終えてから声を出すまでの沈黙が `thinkingSeconds` として記録され、総評の「話し方」でも言及される。
待ち時間を機能として設けると、この沈黙を測れなくなるうえに本番と違う挙動になるため **実装しない**。

当初の予定（参考・実装しない）

| ID | やること |
| --- | --- |
| T-302.1 | 秒数を決める（`THINK_SECONDS`、5〜10 秒程度） |
| T-302.2 | `phase = "answering"` から `THINK_SECONDS` 経過するまで `Recorder` を `disabled` にし、カウントダウンを表示 |
| T-302.3 | 読み上げが終わってからカウント開始 |
| T-302.4 | フォールバック（テキスト入力）にも同じ待ちを適用 |
