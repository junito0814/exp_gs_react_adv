# phase 1：無反応に見える箇所

対応：決定事項 33 ／ NFR-12 ／ US-31 ／ FR-P13, P14, P15・FR-H08・FR-I21

4 箇所はいずれも「押したのに画面が変わらない」ため、ユーザーがもう一度押してしまう。
**二重録音・二重リクエストが実際に起きる**ので、まとめてここで直す。

## 直す箇所と、いま起きていること

| # | 箇所 | いま起きていること |
| --- | --- | --- |
| 1 | `app/history/DeleteButton.tsx` | `disabled` が無く、DELETE から `router.refresh()` の完了までボタンが生きている。連打すると 2 回目以降が 404 になり「見つかりませんでした」のアラートが出る |
| 2 | `app/Recorder.tsx`（手動＝講評モード） | 停止するとボタンがすぐ「🎤 話す」に戻るが、文字起こしは数秒かかる。その間にもう一度押せて二重録音になる（模擬面接側は「文字にしています…」がある） |
| 3 | `app/FaceMeter.tsx` | `face-api` の動的 import → モデル 2 つの読み込み → カメラ起動。その間は映像が黒く「笑顔 0%」と出るため、壊れたように見える |
| 4 | `PracticeClient.speak` / `InterviewClient.speakSummary` | 先に `isSpeaking` を立てるため、**再生ボタンが消えて「⏸ 停止」だけが出るのに音は鳴らない**。音声合成にかかる数秒が無表示 |
