# 待ち時間の表示（ローディング）

対応：決定事項 33 ／ NFR-12 ／ [エピック I](../../03_user_stories/I_loading.md)（US-31〜33）

非同期処理をすべてたどり、「待っているのに画面が変わらない」箇所を洗い出した（2026-09-30）。
影響の大きい順に **3 フェーズ** に分け、1 フェーズずつ完結させる。

## 既にある表示（変えない・文言の基準にする）

## 共通の方針

- 対象は **1 秒以上かかる操作**（NFR-12）。それ未満の処理に表示は足さない。
- 進行中はその操作を **再実行できない**（`disabled`）。表示だけ足して押せるままにはしない。
- 文言は既にある表示に合わせる。ボタンの中は「生成中…」「保存中…」、ボタン外の説明は「〜しています…」。
- 表示は **その操作の近く** に出す。画面全体を覆うオーバーレイは使わない。
- 画像のスピナーは増やさず、テキストで示す（NFR-07 の配色を崩さないため）。
