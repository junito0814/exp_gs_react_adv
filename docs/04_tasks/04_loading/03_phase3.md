## 状態遷移の変更（T-403.3）

```
（変更前）summarizing ──▶ done        ※保存中も「総評をまとめています…」のまま
（変更後）summarizing ──▶ saving ──▶ done
```

`summary` アクションで `saving` に入り、`saved` / `saveFailed` で `done` に進む。
`02_requirements.md` 4.4 の状態遷移図も合わせて更新した。

「面接の最中か」の判定を `interviewing`（`summarizing` `saving` `done` 以外）にまとめ、
カメラと「面接中断」の表示条件をそこに寄せた。

## 実装中に lint で止まった点

`useEffect` の中で同期的に `setState` すると、新しく有効にした lint（T-909）が **error** にする
（`Calling setState synchronously within an effect can trigger cascading renders`）。

そのため「音声を作っている間」は state を立てるのではなく、**派生**で求めた。

```
audioStartedFor  … 音が鳴り始めた質問（audio.onplay で入れる＝コールバックなので可）
preparingQuestion = 質問がある && まだ readyToSpeak でない && audioStartedFor ≠ その質問
```

`readyFor` と同じく「質問文そのものを持つ」形にしたので、往復ごとのリセットが不要。
