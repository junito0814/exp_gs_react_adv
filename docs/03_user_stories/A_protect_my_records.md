# エピック A: ログインして自分の記録を守る

## US-01 Google でログインする
美香として、パスワードを新しく覚えずに使い始めるために、Google アカウントでログインしたい。
- 対応: FR-A01, A02, A05
- AC:
  - [x] 未ログインで `/` を開くと `/sign-in` に移動し、Google ログインボタンだけが表示される
  - [x] ログイン後にトップ画面へ戻る
  - [x] ヘッダーにアカウントアイコンがあり、そこからログアウトできる
  - [x] ログアウト後に `/history` を開くと `/sign-in` に移動する

## US-02 自分の記録だけが見える
陸として、他人に練習内容を見られないために、履歴には自分の記録だけを表示してほしい。
- 対応: FR-A03, A04, H01, D03, X08, X09, X11
- AC:
  - [x] 別アカウントで保存した記録は一覧に出ない
  - [x] 他人の記録の URL（`/history/123`）を直接開くと「見つかりませんでした」
  - [x] 他人の記録の `DELETE /api/sessions/123` は 404 で、削除されない
  - [x] 未ログインで API を叩くと 401
  - [x] 以前の `demo` データは一覧に出ない

## US-34 何が外部に送られるかを知って練習する
陸として、話す内容をどこまで具体的にしてよいか判断するために、練習を始める前に「何が外部に送られ、何が送られないか」を知りたい。
- 対応: FR-P17, FR-I26, NFR-04
- AC:
  - [ ] 模擬面接の開始前（**マイクの許可を求める前**）に、送られるもの・送られないものが読める
  - [ ] 講評モードでも、録音する前に同じ内容が読める
  - [ ] **話した内容と表情を AI が解析する**ことが書かれている
  - [ ] 音声・回答が Groq へ、読み上げの文章が音声合成サービス（Microsoft）へ送られることが書かれている
  - [ ] **カメラ映像は送られない**ことも同じ場所に書かれている
  - [ ] 文言は `lib/messages.ts` の 1 か所で管理され、2 画面で同じ文が出る
  - [ ] 見た目はプロフィール画面の注意事項と同じ（`app/Notice.tsx` を共用）
