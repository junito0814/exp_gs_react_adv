# エピック I: 待っていることが分かる

対応：決定事項 33 ／ NFR-12 ／ タスク [04_tasks/04_loading](../04_tasks/04_loading/README.md)

## US-31 押したことが伝わる（phase 1）
陸として、押したのに何も起きないと不安になり二度押してしまうので、処理中であることを画面に出してほしい。
- 対応: FR-P13, P14, P15, FR-H08, FR-I21
- AC:
  - [ ] 履歴の「削除」を押すと「削除中…」になり、連打しても削除は 1 回だけ
  - [ ] 講評モードで話し終えた後「文字にしています…」が出て、その間は録音を再開できない
  - [ ] カメラの準備中は「カメラを準備しています…」が出る（黒い枠と「笑顔 0%」を出さない）
  - [ ] 「音声読み上げ」を押してから音が出るまで「音声を準備しています…」が出る（講評・総評の両方）

## US-32 画面が切り替わるのが分かる（phase 2）
美香として、履歴のタブを切り替えたときに固まったと思わないように、読み込み中だと分かるようにしてほしい。
- 対応: FR-T07, FR-H09, FR-D06, FR-F07
- AC:
  - [ ] `/` `/history` `/history/[id]` `/profile` の読み込み中に骨組み（スケルトン）が出る
  - [ ] 履歴のタブを切り替えた直後に、前の一覧のまま固まらない
  - [ ] トップの「模擬面接を始める」「講評モードで練習」を押すと、ボタン自体が進行中の表示になる

## US-33 何を待っているのか分かる（phase 3）
陸として、待っている理由が分かるように、表示の文言を実際の処理と合わせてほしい。
- 対応: 決定 33（FR は phase 3 着手時に追記する）
- AC:
  - [ ] 面接の保存中は「保存しています…」と出る（総評の生成中と区別できる）
  - [ ] 「面接を始める」はマイクの許可を待っている間、押せない
  - [ ] 質問の音声を作っている間、その旨が出る（無音の時間に説明がある）
  - [ ] 「再保存」は連打できない
