対応する要件は [02_requirements.md](./02_requirements.md) の各画面節を参照。共通ヘッダーは全画面に付く。

```
│ AI 面接コーチ                                        (👤) ▼   │  ← Clerk UserButton（ログアウト）
└──────────────────────────────────────────────────────────────┘
```

- 保存失敗時：「✓ 保存しました」の位置に「⚠ 保存に失敗しました [ 再保存 ]」。
- 質問取得・総評生成の失敗時：面接官カードの位置に「⚠ 通信に失敗しました [ もう一度 ]」。往復カウンタは保持。
- 「面接中断」押下：`confirm` → 往復 ≥ 1 なら 4-5 へ、0 ならトップへ。
- 読み上げの音声を作っている間：「▶ 音声読み上げ」の位置に「音声を準備しています…」（決定 33 / FR-I21）。
- 総評ができてから保存が終わるまで：面接官カードの位置に「保存しています…」。この間はカメラと「面接中断」を出さない（決定 33 / FR-I24）。
- 「再保存」は押している間「保存しています…」になり、連打できない（決定 33 / FR-I25）。
